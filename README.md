# 教室座位安排

純前端網頁，直接用瀏覽器開啟 `index.html` 即可使用（不需安裝或伺服器）。

資料只存在「這台裝置的這個瀏覽器」裡（localStorage），不會上傳到網路；換電腦、換瀏覽器或清除瀏覽資料就看不到。要在手機、家裡電腦、學校電腦都用：在舊裝置按右上角「💾 備份／搬移」→「複製資料碼」（用 LINE Keep／Email 傳給自己）或「下載備份檔」，到新裝置同一個視窗貼上資料碼或選擇備份檔匯入。資料裡包含老師的安排，請只傳給自己。

### ☁️ 雲端班級（班級代碼＋老師密碼，Firebase）

把 Firebase 專案設定填進 `app.js` 的 `FIREBASE_CONFIG`（步驟見 [`cloud/README.md`](cloud/README.md)）後，左上角會出現「☁️ 雲端」，老師可以用「班級代碼＋老師密碼」建立或登入班級。每個班級是 Firestore 裡的一份文件，登入後修改會自動存到雲端；在其他電腦或手機登入同一個班級代碼，就是同一份資料。兩台同時修改時會詢問要用哪一份；改密碼後其他裝置會被要求重新登入。在學校或別人的電腦用完，請按「登出並清除這台的資料」。沒有設定 Firebase 時，雲端按鈕不會出現，網頁和以前一樣只存在瀏覽器裡。

- **📺 抽籤專用連結**：登入雲端後，在「☁️ 雲端」產生有期限的連結（12 小時～7 天），用 LINE 傳給自己。在學校大屏的電腦點開，直接是抽籤畫面（只有座位表和「抽籤」），沒有後台、不能離開大屏；網址列上的憑證會立刻拿掉，資料只存在那個分頁。抽籤前顯示上次記住的座位（沒有就顯示「？」），抽完結果自動存回雲端。可隨時「停用所有抽籤連結」。

## 功能

- **班級人數 26～40 人**：可調整人數、逐一新增／移除，或「批次貼上名單」（`王小明 男 152 近視`）。
- **批次貼上名單**：每行一位，可寫座號、姓名、性別、身高、近視、成績，例如 `1 王小明 男 152 近視 85分`（開頭的數字是座號；100 以下的數字或「85分」是成績；101 以上的數字或「152cm」是身高）。
- **批次設定性別**：指定座號範圍設為男／女（例：1～15 男、16～30 女），或一鍵「單號男、雙號女」「單號女、雙號男」「全部清除」。
- **學生卡片**：每位學生一張卡片，可直接編輯座號、姓名、性別、近視、身高（填公分，或選 矮／中矮／中／中高／高）、備註；按「條件設定」可設定
  - 與同學的關係：先選「不可相鄰／不可同組／盡量同組」，再點同學名字（雙向生效）
  - 座位偏好：前後（不限／盡量前排／盡量後排）與左右（不限／盡量外側／盡量中間），可以同時設定
  - 自訂條件（可任意新增、刪除），例如「需要關注 → 盡量前排」、「容易聊天 → 彼此分散」
- **排座條件**：視力（近視坐前排）、身高（矮前高後）、性別（男生旁邊盡量放女生，女生不限）、成績（高低分互助：分組時各組平均接近，其他版型成績相近的不坐隔壁，預設關閉）可開關並設定重要程度（低／中／高）。
- **📌 上次座位**：換好座位後按「📌 記住這次座位」（抽籤全部抽完時籤筒畫面也有這個按鈕），最多記住 3 次。排座時會避免坐最近 1～3 次坐過的位子（🔁 換位子），並把上次坐左側的換到右側、右側的換到左側（↔ 左右換邊）；手動調整時，還沒換開的人會列在「檢查結果」提醒。每次記住時會自動下載一份備份檔。
- **📚 紀錄／方案**：「過去的座位」可看最近 10 次記住的座位縮圖、放大、套用回座位表；「我的方案」可把目前座位（可連同老師的安排）存成有名字的方案，之後一鍵載入、覆蓋或刪除。
- **座位型式**：直排（每排桌數、兩兩併桌）、分組（3～10 組，人數平均分配）、ㄇ字型（人數多時自動做成內外雙層）。
- **座位圖（可存很多張）**：預設有「本班」（依班上座位圖，27 個座位、5 組）；按「＋ 新增座位圖」取名字，再選從直排／分組／ㄇ字型開始，或複製目前畫面。不要的座位圖按名字旁的 × 刪除。
  - 在空白處點兩下新增座位、按桌子左上角 × 刪除座位、把座位拖到空白處移動，位置會自動記住
  - 「依位置自動分組」：把靠在一起的桌子自動分成第 1 組、第 2 組…（單獨的桌子不分組），之後可再個別調整
  - 新座位可指定加入哪一組（自動加入最近的組、指定組別、新的一組或不分組）；點一下座位也能更改它的組別
- **自動排座**：綜合所有條件計算最佳座位；🔒 可鎖定特定學生的座位不被移動；也可隨機排座。
- **🎰 抽籤排座**：按「抽籤」進入籤筒畫面，右邊列出所有座號。學生一個一個上台：點自己的座號 → 按「搖籤筒」（或直接點籤筒）→ 跳出寫著名字的籤，他的座位在座位表上亮起來。抽過的座號會變灰不能再抽；「全部揭曉」可一次顯示剩下的人。結果事先依老師的設定安排好（依條件或完全隨機，都會遵守老師的暗中安排）。
  - **⭐ 自選座位**：籤筒畫面上方切到「自選座位」，表現好的同學先點自己的座號、再點想坐的位子；剩下的人再切回「抽籤」。學生選了就坐（只有已經有人的位子不能選）。如果選走的是老師內定給別人的位子，那位同學會改坐老師事先設定的「備案位置」（在「說明」點內定的座位設定，可設多個、依序使用）；沒有備案就依抽籤設定重新安排。這些調整只影響這一次抽籤，老師原本的設定不會被改掉。
  - 音效：搖籤聲、出籤「叮」、全部抽完的音樂，可在「說明」關閉。
- **📺 大屏模式**：投影給學生看時使用，只顯示班級名稱、座位表和「抽籤」按鈕；檢查結果、圖例、工具列、座位上的近視／身高／自訂條件標記全部隱藏，也不能拖曳。右上角「離開大屏」回到老師畫面。
- **老師暗中安排**：按工具列看起來很普通的「說明」按鈕開啟（再按一次或「隱藏」關閉）。可設定某個座位「一定抽到」誰、「一定不會抽到」誰，以及「誰和誰不能坐隔壁」。🎰 抽籤（依條件或完全隨機）、🎲 隨機、自動排座都會遵守；關閉時座位表、名單與抽籤畫面都不會顯示，抽籤開始時也會自動隱藏。
  - 抽籤用過的內定會被記下；下次按「自動排座」或「隨機」時會先問「上次抽籤用的座位說明還在，要先清空嗎？」，「說明」面板也會提醒。
  - 「照目前座位全部內定」：把已經排好的座位整份設成抽籤結果；把個別座位改回「不指定」就能留給學生隨機抽。
- **拖曳調整**：
  - 「調換學生」模式：把學生拖到另一個座位即互換，拖到空白處則整個座位移過去
  - 「移動桌椅」模式：自由拖動桌子位置，可新增或刪除空桌
- **檢查結果**：即時列出違反的規則，座位上以紅框／黃框標示。
- 座位上的名字會依桌子大小自動放大／縮小。
- 復原、講台在上／下視角切換、列印座位表、🖼 下載座位表圖片（PNG，可傳到 LINE）、匯出／匯入 JSON 備份（超過 14 天沒備份會提醒）。
