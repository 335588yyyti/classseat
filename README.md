# 教室座位安排

純前端網頁，直接用瀏覽器開啟 `index.html` 即可使用（不需安裝或伺服器），資料自動存在瀏覽器中。

## 功能

- **班級人數 26～40 人**：可調整人數、逐一新增／移除，或「批次貼上名單」（`王小明 男 152 近視`）。
- **批次設定性別**：指定座號範圍設為男／女（例：1～15 男、16～30 女），或一鍵「單號男、雙號女」「單號女、雙號男」「全部清除」。
- **學生卡片**：每位學生一張卡片，可直接編輯座號、姓名、性別、近視、身高（填公分，或選 矮／中矮／中／中高／高）、備註；按「條件設定」可設定
  - 與同學的關係：先選「不可相鄰／不可同組／盡量同組」，再點同學名字（雙向生效）
  - 座位偏好：前後（不限／盡量前排／盡量後排）與左右（不限／盡量外側／盡量中間），可以同時設定
  - 自訂條件（可任意新增、刪除），例如「需要關注 → 盡量前排」、「容易聊天 → 彼此分散」
- **排座條件**：視力、身高、性別可開關並設定重要程度（低／中／高）。
- **座位型式**：直排（每排桌數、兩兩併桌）、分組（3～10 組，人數平均分配）、ㄇ字型（人數多時自動做成內外雙層）。
- **座位圖（可存很多張）**：預設有「本班」（依班上座位圖，27 個座位、5 組）；按「＋ 新增座位圖」取名字，再選從直排／分組／ㄇ字型開始，或複製目前畫面。不要的座位圖按名字旁的 × 刪除。
  - 在空白處點兩下新增座位、按桌子左上角 × 刪除座位、把座位拖到空白處移動，位置會自動記住
  - 新座位可指定加入哪一組（自動加入最近的組、指定組別、新的一組或不分組）；點一下座位也能更改它的組別
- **自動排座**：綜合所有條件計算最佳座位；🔒 可鎖定特定學生的座位不被移動；也可隨機排座。
- **拖曳調整**：
  - 「調換學生」模式：把學生拖到另一個座位即互換，拖到空白處則整個座位移過去
  - 「移動桌椅」模式：自由拖動桌子位置，可新增或刪除空桌
- **檢查結果**：即時列出違反的規則，座位上以紅框／黃框標示。
- 座位上的名字會依桌子大小自動放大／縮小。
- 復原、講台在上／下視角切換、列印座位表、匯出／匯入 JSON 備份。
